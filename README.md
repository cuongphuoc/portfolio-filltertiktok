# PC34 Studio Portfolio

A modern, dark-mode portfolio website for **PC34 Studio**, specializing in TikTok filters, AR, and VR experiences.

## Features
- Cyberpunk Dark Mode Aesthetic
- TikTok Filter Video Embeds
- Multi-language Support (English & Vietnamese)
- Glassmorphism UI & Neon Effects
- Responsive Design

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (ES6+)
- Lucide Icons
